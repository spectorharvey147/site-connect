# Release validation — 23 September 2026

This release implements UTF-8 comma-delimited SAP files, a main abstract workbook, sequential six-digit journal IDs, daily sequential batch IDs, configured SAP project codes, and row-wise approved amounts with submitted-amount ceilings. All approval views retain bill/no-bill amounts, descriptions, and remarks.

It also moves authentication to server-side verification, protects session/password tables, restricts claim access by role and assignment, makes claim files private with authorized signed links, and saves new claims/expenses/ledger entries atomically. Existing SHA-256 passwords are upgraded to bcrypt at successful login. The final security migration invalidates old sessions; users must sign in again.

Validation completed locally:
- 56 application tests passed, including CSV layout, workbook sheets, export dialog, and row approval calculations.
- TypeScript compilation and production build passed.
- Database integration checks passed on a disposable database built from the production schema: authentication, role restrictions, password reset, atomic submission rollback, distinct claim numbers, all four approval stages, approved amount ceiling, accounting setup and SAP export.
- npm audit reports zero known vulnerabilities after dependency updates.

Limitations: the repository still has pre-existing loose-type ESLint findings and React hook/export warnings. These are recorded separately from passing build/tests; this is not a claim of a completely error-free project. The production bundle also emits a size warning. No real claims were approved/paid and no notification emails were sent during validation. SAP import itself must be confirmed in the user's SAP system.

Deployment order: additive authentication/submission functions; authenticated edge functions; frontend build; final role/file restrictions and migration history reconciliation; live anonymous-access and temporary-account smoke checks. Local backups, credentials and test artifacts under .tmp and scripts/backups are excluded from Git.

Production release completed through PR #22. Live checks confirmed server-side login, blocked anonymous password/session/reset-token access, hidden unrelated claims, authenticated file upload, signed download, and blocked public file access. The disposable file, temporary account, and test sessions were removed. Final browser dashboard inspection was interrupted by an approval-review usage limit; API checks completed successfully.
